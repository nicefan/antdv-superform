## 2026-09-12：配置契约调整

用户明确确认“配置图标都应该为渲染函数”，取代本任务此前直接接受 Vue 组件对象的方案。统一使用 `() => VNodeChild`：例如 `() => h('span', { class: 'i-icon-user' })`，使用组件时写 `() => h(UserIcon)`。这仍是实施授权，不是人工完成验收。

## 范围与设计影响

- Core 自带仅依赖 Vue 的 SVG 图标，官方 Adapter 共用。图标继承 currentColor 和 em 尺寸，加载图标保留旋转表现。
- `add/delete/edit/detail/submit/search/reset` 七个动作提供默认图标。全局 `defaultButtons`、方法配置及单个动作可以覆盖；单个动作显式 `icon: undefined` 可移除图标，`labelMode: 'label'` 可只显示文字。
- 图标配置统一为 `() => VNodeChild`，不接受组件对象或字符串名称。slot 场景直接传 `icon`，非 slot 场景直接调用 `icon?.()`；CSS 类图标通过返回对应元素使用。
- 保留 Icon capability 的内部语义键，映射值同样使用渲染函数。SDK 仅共享 `builtInIcons`；删除 `getIconNode`、`renderUIIcon`、`renderIconComponent`、`renderAntdvIcon` 和 `IconAdapter.render`，业务图标不再经 Adapter 转发。
- 补齐 Element Plus 按钮 icon/labelMode 渲染和 Tag 图标 slot 映射；标签图标函数直接传给 slot，Collapse 标题及 AntDV Tab 关闭图标消费渲染函数配置。
- 按钮配置直接保存渲染函数，显式设置 undefined 时可清空默认图标。
- 删除根包、AntDV 产品和示例的图标库直接依赖及导入；锁文件保留 UI 框架自身需要的传递依赖。
- 不改变动作执行、权限、确认、表单模型、表格请求或 CRUD 业务语义。

与升级架构的差异：原本实际图标由 Adapter 提供；本任务提出将框架无关 SVG 默认实现放在 Core，Adapter 保留组合和渲染协议。该实现方向已获授权，但正式架构基线和 ADR 需等待人工验收完成后同步。
