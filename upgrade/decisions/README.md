# 架构决策记录

ADR 用于保存 Git diff 无法表达的设计理由，防止长期升级中重复推翻已经确认的边界。

状态含义：

- `提议`：仍需确认，不得作为强制约束。
- `已接受`：后续实现必须遵守。
- `已取代`：由新的 ADR 替代，旧文件保留历史原因。
- `已废弃`：不再适用，但保留历史记录。
