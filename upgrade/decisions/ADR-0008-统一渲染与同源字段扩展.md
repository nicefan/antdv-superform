# ADR-0008：统一渲染与同源字段扩展

状态：已接受，依据 beta.2 已实现代码及用户授权；整理日期：2026-09-23。

## 决策

固定 UI 声明集中在 uiComponents，创建 Adapter 时归一化；字段和固定 UI 的 render 统一使用上下文对象。处理器仅输出框架无关 state，model 与原生事件在属性适配阶段合成一次。

同源字段通过名称目录与 fieldSources 共享原始组件。Element Plus 的 TextArea、InputPassword、InputSearch 和范围字段可以使用扩展名称，不要求 UI 库提供同名独立导出；原生属性差异仍由各 UI 包负责。

## 原因与影响

统一上下文减少多种回调签名和重复事件合成；组件、默认值与服务就近声明，避免 Core 重新识别 UI 类型。缓存原始组件与最终字段配置分别管理，防止独立适配组件递归取得自身。

共享原始组件使手动注册与自动导入遵循同一规则，扩展字段不需要重复导入；fixedProps 锁定字段语义，defaults 允许用户覆盖。搜索异步状态属于业务，InputSearch 不依据 Promise 隐式修改 loading。

该决策细化 ADR-0001/0002 的字段边界；相关旧签名以本决策和当前架构总览为准。历史 ADR 保留设计背景，不作为当前代码示例。
