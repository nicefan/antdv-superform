# ADR-0007：图标函数与复合字段局部校验

状态：已接受。日期：2026-09-16。

## 决策

- 图标配置统一为 `() => VNodeChild`，支持组件与 CSS 图标。Core 提供默认 SVG，Adapter 映射内部语义图标。
- 紧凑布局接收各字段节点，分别提供首尾上下文。
- 复合字段通过 Form 提供的局部校验方法复用表单实例，由 Adapter 转换底层调用。
- 行按钮只携带操作上下文，不注册字段路径；列表模板保留规则，绑定行后使用实际路径。

## 原因与影响

渲染函数统一了不同图标来源，消费端无需识别组件对象或解析图标名。复用表单实例避免依赖框架内部上下文，局部校验限制了输入变化的校验范围。按钮不注册字段路径，可避免与整行分组的注册冲突。

第三方 Adapter 的 `icons.semantic` 使用渲染函数；支持复合字段局部校验时，实现 `form.validateField(instance, path)`。
