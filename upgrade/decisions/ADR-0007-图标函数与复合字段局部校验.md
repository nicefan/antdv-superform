# ADR-0007：图标函数与复合字段局部校验

状态：已接受。日期：2026-09-16。依据：用户确认图标统一为渲染函数、复用 exaProvider 表单实例局部校验，并确认本次代码和任务完成。

## 决策

1. 业务 icon 为 () => VNodeChild，icon slot 直接使用函数；非 slot 场景调用取得节点。Core 内置 SVG，官方 Adapter 共用，Icon capability 仅保留 semantic 映射；不再需要图标库直接依赖或 renderUIIcon 等包装。
2. 紧凑布局必须直接获得字段节点，不能把整个 Collections 当作单个紧凑项。Collections 通过插槽交出节点，布局依旧由 Adapter 实现。
3. Form 在 exaProvider 提供 validateField(path)，封装 formRef。Adapter 的可选 validateField(instance, path) 转换底层方法；支持复合字段局部校验的 Adapter 必须提供，不回退整表校验，不依赖框架内部 context。
4. 无字段列表模板保留规则，绑定行后使用实际路径；行按钮只需要 parent/index，不建立 propChain。移动行时只更新已有路径。

## 原因与影响

渲染函数同时支持组件和 CSS 图标，无需识别组件对象或图标名。局部校验复用已有实例，避免框架私有上下文依赖，也避免输入一组字段时验证整张表单。

AntDV Next 使用 validateFields([path])；Element Plus 使用 validateField(path.join('.'))。路径与表单项注册需一致，行按钮不得占用分组注册键。第三方 Adapter 需适配局部校验和语义图标函数。

本决策只描述架构与已接受行为；本次未执行测试或构建。
