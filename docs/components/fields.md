# 字段类型

## 输入

`Input`、`Textarea`、`InputNumber`、`AutoComplete`、`TagInput`、`TagSelect`

## 选择

`Select`、`TreeSelect`、`Radio`、`Checkbox`、`Switch`

## 日期与时间

`DatePicker`、`DateRange`、`TimePicker`、`TimeRange`

## 展示与结构

`Text`、`HTML`、`Hidden`、`InputSlot`、`InfoSlot`

## 文件

`Upload`

组件属性放在 `attrs` 中，表单级规则如 `field`、`label`、`required` 保持在字段顶层。
