# 介绍

Antdv SuperForm 是基于 Vue 3 和 Ant Design Vue 的配置式表单与表格组件库。它用统一 schema 描述字段、校验、查询、编辑和详情展示，适合结构重复、联动较多的中后台页面。

## 为什么使用

  <div class="feature-card"><strong>减少重复</strong><p>同一字段配置可以服务于编辑、查询、表格与详情。</p></div>

## 环境要求

- Vue `>= 3.3.13`
- Ant Design Vue `>= 3.2.20`

两者都是 peer dependencies，需要由应用安装。
