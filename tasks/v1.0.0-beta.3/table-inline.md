# 表格行编辑

日期：2026-09-28。状态：已实现，待人工验证。

实施前：逐格 Form 仅校验已挂载字段，边距及校验文本偏离原版；固定单行草稿，保存结果包含刷新结果。

本轮修复：AntDV 可见与补充校验项同路径注销导致漏校验，现共享草稿值但隔离登记路径，并补齐逐行校验范围传递；弹窗新增在打开时按当前记录确定源数组位置，避免分页下标错位；紧凑样式统一覆盖行内与整表编辑。reload 保持仅调用，异常由请求层处理。

- 共用 Form，按草稿隔离模型及字段路径；保存只校验当前行全部规则，包含未展示和只读字段。两套 Adapter 支持指定路径批量校验；显式校验串行，接口请求可并行。
- 默认多行同时编辑，草稿绑定稳定行键，保存/取消及保存锁按行独立。`rowEditor.singleEdit: true` 限制单行，并在实际查询请求前清理编辑状态；本地翻页不清理。
- 直接使用当前记录，不递归重新定位。新增/更新成功后本地写回，配置 query API 时独立刷新；刷新失败不改变保存结果。保存期间不禁用输入。
- 行内及整表编辑单元格无额外边距、不显示校验文本，保留错误状态及消息提示。
