### Upload UI 协议调整（2026-09-25）

- 新增 `UIUploadState/UIUploadFile`，统一接入固定 UI 的 `state/attrs/slots` 协议。Core 管理选入、校验、列表、上传进度、提交任务、删除及预览；Adapter 提供原生选择入口和列表呈现。
- 删除 `UploadAdapter` 服务、`listIgnore/keepCustomFile` 及 `uploadTrigger` 渲染入口；原生 Upload 不再上传、不管理领域文件列表，不再向 Core 传递原生文件和事件对象。
- 不保留旧公开配置兼容：`showUploadList` 改为 `showList/removable/downloadable/previewable`，`beforeUpload` 改为 `beforeSelect`，删除拦截改用 `beforeRemove`，图片判定改用 `isImage`。原生请求和列表生命周期属性从公开类型中移除。
- 自定义模式原始文件使用 `file`，不再使用 `originFileObj`；变更回调统一接收 `{ file, fileList }`。配置下载接口或回调时默认提供下载入口，可用 `downloadable: false` 禁止下载。
