# v1.0.0-beta.2 开发阶段

日期：2026-09-16；更新：2026-09-18

状态：输入组件协议及专项配置调整已实现；类型检查、测试、构建均未执行，待验证及用户确认。

## 范围与已确认决策

- 第一阶段只涉及动态输入字段及共享选项的必要消费者。Form、Layout、Container 和其它 capability 的 facade 不在本次实现范围。
- 真实输入组件由现有自动导入或初始化参数提供。纯名称目录与字段差异表分离；原始组件池与最终 field 配置缓存分离。
- Core 处理专项配置；仅在配置 labelField 且未配置顶层 options 时，读取 attrs.options/fieldNames 查找标签，不生成标准 options 或 Switch 专项状态。专项结果与 attrs、binding 分开传给 UI package。
- 删除字段独立 render 入口，统一用 h 渲染。原始组件只接收最终原生参数；独立适配组件显式接收 effectData、model、option、attrs、binding、state。
- UI package 配置默认 model，特殊字段只声明差异；通过 SDK 纯辅助函数提前固化转换实现，Core 不逐次解释 model。
- 字段提供 adaptProps、adaptSlots。Core 包装 slot 的业务上下文，Adapter 再适配，用户 slot 优先，生成节点保持延迟执行。
- 顶层 options 改为配置包，source 与 dictName 可同时配置，source 优先并输出警告，忽略 dictName；fieldNames、valueToNumber、labelAsValue 收入包内。labelField、stringifyValue 留在字段顶层。
- Select / SelectV2 不提供搜索专项处理；原生 onSearch、remoteMethod、过滤及 loading 配置直接透传，InputSearch 也不提供搜索专项处理。
- Input / InputSearch 均不提供 onSearch 专项包装或 loading。InputSearch 保留原生组件，原生事件直接透传；顶层事件沿用通用事件上下文机制。
- Switch 固定 options 第 0 条 unchecked、第 1 条 checked；删除 firstIsChecked、valueLabels 及从 attrs.defaultChecked 推导模型值的逻辑。初始值只由既有 initialValue 流程建立。
- 顶层 disabledDate 保留，调用签名为 disabledDate(effectData, ...原生参数)，包含 UI 提供的临时选择参数；attrs.disabledDate 原样透传，顶层配置存在时覆盖。

## 实现与可观察 API 变化

1. src/adapter/runtime.ts 保留初始化锁定；fieldRegistry.ts 保留手动/自动注册优先级和原始池。SDK 新增 useUIComponent，只读已加载原始缓存，不触发最终 field 解析。
2. resolveUIField 缓存 type、component、adapted、defaults、processors、adaptProps、adaptSlots。移除此前新增的 FieldRender / renderField；公开 FieldState、FieldPropsAdapter、ResolvedField。
3. UIAdapter 使用 supportedFields、adaptFieldProps、fields；FieldAdapter.component 为可选独立适配组件。输入字段 defaults 与应用 configure({ defaultProps }) 分开，后者未更名。Core 使用 Vue mergeProps 合成默认属性、attrs 与标准专项 props（当前为 options）：class/style 按原生规则合并，用户同名样式优先，保留未覆盖的默认样式。
4. SDK 新增 fieldComponentProps，统一声明 type、option、model、effectData、binding、state、attrs，并保留必填类型推导；TreeSelectField 已复用。SDK 提供 createFieldPropsAdapter、defineFieldAdapters、combineFieldHandlers，供 UI package 在定义阶段固定 model 协议并组合原生监听器。定义辅助方法接受局部 model 配置，输出运行时字段不再携带 model 描述。
5. 模型绑定存在时覆盖原生值，包括 undefined；原生更新监听器仍执行原参数，不能覆盖 Core 写回。disabled 有专项结果时才覆盖，继承 true 优先于子字段 false；未配置时保留原生值。placeholder 在 Core 生成，仅用于兜底。
6. 共用 options processor 负责选项解析及递归 children 查找；通过 useVModel 的 onUpdate:labelValue 同步标签，标签序列化与路径写回集中在 useVModel。picker 提供单个 placeholder，range 提供两端 placeholder 数组；switch 只输出两种状态并复用标签绑定；tree 的原生标签参数和字段映射由 UI package 处理，再调用同一标签更新入口。
7. 公开 OptionsSource、OptionsConfig；InputSearchFieldOption 已删除。删除 InputFieldAttrs、InputFieldOption、SwitchFieldAttrs；SwitchFieldOption 不再包含 valueLabels。options 内不保留 valueToLabel 别名，顶层 dictName/valueToNumber/labelAsValue 不再作为输入选项配置读取。
8. Collections、FieldProcessorRenderer、TagInput 统一 h；表格三个内联编辑入口同步传递原生 attrs 与专项状态。
9. useOptions、详情展示、TagSelect、表格 TabsFilter 改用 options 配置包，编辑与展示共用归一化；表格展示仍在首次取得行上下文时加载选项。按钮 dropdown 的原有数据源类型保持不变。
10. OptionsConfig.fieldNames 新增 children 映射，选项递归归一化与查找覆盖子节点；原生选项兼容仅用于配置 labelField 时查找标签，详情展示和 TagSelect 不新增该兼容路径。RadioGroup 删除专用 adaptProps，不再转换 label 节点。删除 FieldState.onValueChange，树选择适配直接调用 binding['onUpdate:labelValue']。Element Plus TreeSelect 通过独立适配组件监听 selectRef.selectedLabel（仅配置 labelField 时），覆盖初始值、外部赋值及异步标签更新；单选清空标签为组件库的空字符串，多选为空数组。真实组件仍从 useUIComponent 缓存取得，element-plus 仅导入实例类型。
11. 两个产品的字段名称目录、初始化校验、名称保留及 resolver 共用纯名称目录。缺失真实组件仍明确报错。schema 自定义 render 与其它 capability 的 render 不属于被移除的字段 render 协议。

12. FieldAdapter.component 支持字符串原始组件目标；原始池解析别名，最终 field 仍按 Schema type 缓存。Element Plus 自动导入将范围别名注册到原始名称并复用导入，名称目录、全量组件表、Schema 属性和扩展类型同步加入别名；别名模式为固定配置：DateRangePicker 的 type、TimeRangePicker 的 isRange 通过 fixedProps 声明，不允许被原生 attrs 覆盖；fixedProps 是通用字段协议，不限于日期别名。
13. picker 生成“请选择{label}”，range 生成“请选择开始/结束{label}”数组，getAttrs 将其作为默认值合成。AntDV 日期/时间组件使用组件库默认提示；Element Plus 范围别名直接将 placeholder 数组映射为 startPlaceholder/endPlaceholder，分别保留显式原生提示。原始 DatePicker/TimePicker 仍支持通过原生 type/isRange 进入范围模式，此时将单个默认提示用于两端。原生显式提示和空字符串优先；不按 endField 判断 UI 范围模式。
